# What's new in Caveland Revive

## 1.1 (27 November 2026)

### Bigger screens, bigger cave view
- **Resizable game view:** drag the bottom-right corner of the frame around the cave to make
  the view as big as you like. The buttons, the wizard and the info bar move along, and the
  info bar stays centred below the view.
- **Window and full screen:** resize or maximize the game window and the cave view grows with
  it.
- **Zoom with the mouse wheel:** from 50 % (see much more of your cave) up to 400 %, always
  around the mouse pointer.
- **UI scaling with F6:** 1x, 2x or 3x for high-resolution screens.
  Only the sizes that fit on your screen are offered.

### Nicer picture
- **Smoother light:** the light and the darkness of the caves now have soft, even gradients
  instead of visible steps.
- **Smoother scrolling:** while you scroll or drag the view, the picture is redrawn in between
  the game's own steps; the game itself does not run any faster.

### Camera windows
- Camera windows outside the info bar can now be **resized** at their borders. Back in the info
  bar they snap to their normal size again.
- Camera windows from a save game always land in a free place of the info bar, even if the
  layout has changed since.

### Playing
- **Fast mode with F7:** the game runs twice as fast; F7 again switches back to normal speed.
  The title bar shows when fast mode is on.
- **Loading from the main menu:** the music now starts once the loaded game is there, no longer
  while the load dialog is still open.

### Save games
- Save games from version 1.0 and from the 1996 game load as before.
- New save games also remember the size of the view and the zoom.

## 1.0 (24 November 2026)

The first release of Caveland Revive, 30 years after the original.

- **Runs on today's Windows:** the 1996 game, rebuilt for Windows 10 and 11, 64-bit.
- **One single file:** all game data is inside `Caveland-Revive.exe`. Download, start, play:
  no installation, no CD.
- **German and English** in the same file. The game picks the language of your Windows;
  `/english` or `/deutsch` forces one.
- **Music:** the original Caveland songs, now with smooth crossfades from one song to the next.
- **Scrolling** with the left mouse button too (drag), not only with the right one.
- **Credits** in the main menu: the team of 1996 and a few words to the fans.
- Several small bugs from 1996 fixed.
